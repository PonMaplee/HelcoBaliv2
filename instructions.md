# Development & Knowledge Graph Workflow Instructions

## 0. Mandatory Initial Checks
- **Read `.agents/AGENTS.md`**: Always review and adhere to project rules.
- **Read `DESIGN_ANALYSIS.md`**: Review the complete UI/UX design specifications, design tokens (colors, typography, breakpoints), component breakdowns, and animation standards before implementing or modifying any frontend interface.
- **Read `graphify-out/GRAPH_REPORT.md`**: Check community hubs, god nodes, surprising connections, and suggested architectural questions before starting work.

## 1. Mandatory Technology Stack & Conventions
Setiap pengembangan fitur, komponen, atau styling **wajib memakai ekosistem teknologi yang sudah terpasang** di dalam codebase:
- **Core Framework:** React 19 (`react`, `react-dom` v19) — Gunakan functional components, React hooks modern, dan manfaatkan optimasi React Compiler.
- **Build Tool & Bundler:** Vite 8 (`vite`, `@vitejs/plugin-react`).
- **Styling Engine:** Tailwind CSS v4 (`@tailwindcss/vite`) — Gunakan `@theme` tokens di `src/index.css` (Gold: `--color-amber-500` / `#D4AF37`, Amber: `--color-amber-600` / `#C5A017`, Base Dark: `#050505`). **Jangan** membuat file konfigurasi `tailwind.config.js` versi lama atau styling ad-hoc yang bertentangan dengan design tokens.
- **Animation & Motion:** Framer Motion v12 (`framer-motion`) — Gunakan token animasi tersentralisasi dari `src/lib/animations.js` (`fadeUp`, `staggerContainer`, `floating`, `glowBreathing`, `heroZoom`) dan `<AnimatePresence>` untuk transisi unmount.
- **Routing & Navigation:** React Router DOM v7 (`react-router-dom`) — Gunakan `<BrowserRouter>`, `<Routes>`, `<Route>`, `<Link>`, dan `NavHashLink` untuk smooth scroll hash anchors.
- **Iconography:** Lucide React (`lucide-react`) — Gunakan ikon dari paket ini untuk konsistensi UI.
- **SEO & Metadata:** React Helmet Async (`react-helmet-async`) — Integrasikan selalu melalui komponen `src/components/SEO.jsx`.
- **Typography:** Gunakan font Google Fonts yang telah diimpor: *Playfair Display* (`font-serif`) untuk headlines/aksen puitis dan *Inter* (`font-sans`) untuk body text.
- **Aturan Dependensi:** **Dilarang menambahkan library styling/UI lain** (seperti Bootstrap, MUI, Chakra, Tailwind v3 lama) yang bertentangan dengan stack yang sudah ada.

## 2. Graphify System Rule
Before you generate code, modify architecture, or answer questions about how this project works, you MUST consult the local codebase map generated by Graphify.

- **Locate the Graph:** Always read the contents of the `graphify-out/` directory located in the root of this workspace before taking action.
- **Trace Dependencies:** Use the structural data inside the map to understand how files, UI components, backend logic, and database schemas connect. 
- **Do Not Guess:** Never hallucinate file paths, imports, or method names. Rely strictly on the exact relationships defined in the graph.
- **Vibecoding Alignment:** When making sweeping, multi-file architectural changes, ensure your proposed updates align seamlessly with the existing project structure mapped in `graphify-out/`.

## 3. Post-Coding Graph Update Standard
- **After every coding session** or whenever making updates to project code/documentation, you **must update the knowledge graph** to maintain graph accuracy across sessions.
- Run the update command:
  ```bash
  /graphify . --update
  ```
